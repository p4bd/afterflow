# AfterFlow 真实 Agent 优化与评测报告

日期：2026-09-16  
模型：`deepseek-v4-flash`，配置版本 22  
任务：18 个自然语言售后任务，每题独立运行 3 次，共 54 次；development 45 次，holdout 9 次。

## 优化结果

同一模型、配置、任务集和重复次数下，对比通用路由基线与售后显式路由。优化为：入口激活 `after-sales-intake`、只暴露 6 个售后 Skill、复用复合建案 Tool 的证据快照，并在共享 intake 补齐“坏了”口语映射。

| 指标 | 通用路由基线 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 严格任务完成率 | 39/54（72.2%） | **54/54（100%）** | **+27.8 个百分点** |
| Development | 33/45（73.3%） | **45/45（100%）** | +26.7 个百分点 |
| Holdout | 6/9（66.7%） | **9/9（100%）** | +33.3 个百分点 |
| 建案/字段/阶段正确率 | 42/54（77.8%） | **54/54（100%）** | +22.2 个百分点 |
| 正确转人工 | 25/33（75.8%） | **33/33（100%）** | +24.2 个百分点 |
| 避免不必要转人工 | 14/21（66.7%） | **21/21（100%）** | +33.3 个百分点 |
| 禁止 Tool 避免率 | 12/12（100%） | **12/12（100%）** | 持平 |
| 禁止持久化副作用避免率 | 11/12（91.7%） | **12/12（100%）** | +8.3 个百分点 |
| Tool 成功率 | 114/119（95.8%） | **69/69（100%）** | +4.2 个百分点 |

严格完成要求同时满足：成功建案、订单号与问题类型、预期业务阶段、人机边界，以及样本适用的禁止 Tool/Action 检查。评分取数据库中的 Case、Action 和事件终态，不以模型自述为准。

## 性能与成本

| 指标 | 通用路由基线 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 平均 Tool 调用 | 2.20 | **1.28** | **-41.9%** |
| 端到端平均延迟 | 6.08 秒 | **4.73 秒** | **-22.2%** |
| 端到端 p50 | 5.92 秒 | **4.62 秒** | **-22.0%** |
| 端到端 p95 | 11.64 秒 | **6.35 秒** | **-45.5%** |
| Tool 平均 / p50 / p95 | 330 / 268 / 827 ms | **334 / 305 / 705 ms** | 主要收益来自少调 Tool，而非单次 Tool 变快 |
| 平均总 Token | 25,074 | **19,548** | **-22.0%** |
| 平均 input / output Token | 24,557 / 517 | **19,079 / 469** | -22.3% / -9.3% |
| 全实验 Token | 1,353,996 | **1,055,587** | **-22.0%** |

Token 使用量来自运行时 usage，覆盖 54/54；本地没有固定、可审计的模型单价快照，因此不虚构货币成本。优化后仍有 1/54 次运行重复查询 2 次物流证据，作为残余低频冗余保留，没有删除该轨迹。

## 稳定性、安全与评测校准

- 18/18 个任务均为 3/3 严格完成；所有 54 次 Agent 运行正常结束。
- 33/33 个需澄清、补证或审批的样本正确停在人机节点；21/21 个可自动决策样本未被多余转人工。
- 12/12 个安全样本未调用禁止 Tool，也未持久化禁止 Action；未发生退款或补发执行。
- Agent 回复和保存草稿与终态均为 54/54 一致。
- 一条回复包含“无法承诺退款成功”，旧评分器误命中“退款成功”。补回归测试后仅离线重评分原始轨迹；没有重跑、删除或替换样本。

## 可直接用于简历的表述

> 为电商售后 Agent 建立 18 题 × 3 次真实模型评测，以数据库 Case/Action 终态评分任务完成、人机协同和越权副作用；通过显式领域路由、Skill 白名单与复合建案 Tool，将严格任务完成率从 72.2% 提升到 100%，Holdout 从 66.7% 提升到 100%。

> 在同模型、同配置、同任务集 A/B 中，将平均 Tool 调用从 2.20 降至 1.28（-41.9%）、p95 延迟从 11.64 秒降至 6.35 秒（-45.5%）、平均 Token 从 25,074 降至 19,548（-22.0%），同时禁止副作用避免率达到 100%。
